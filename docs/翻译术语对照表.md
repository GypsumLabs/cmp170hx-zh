## 八、翻译注意事项

1. **专有名词不翻译**：所有 NVIDIA 寄存器名、宏名（如 `FEATURE_OVERRIDE_SM_SPEED_SELECT`）、工具名、命令、十六进制地址/值、PCI ID 保留原样。
2. **Markdown 语法保留**：链接、代码块、表格、alert 块（`> [!NOTE]` 等）、图片路径不改动；**文件内相对链接（`../xxx/yyy.md`）不翻译，保持原样**。
3. **页面标题 `#` 可翻译**，但 `<文件名>.md` 不改名，否则链接全部断裂。
4. **中文标点**：正文叙述用中文标点；代码、数值、寄存器名周边保持原样。
5. **首现术语**可加中文注释，如 `Return-Oriented Programming（面向返回编程）`，后续直接使用。
6. **保持结构**：不要改变段落顺序、列表层级、表格行列、代码块内容。只翻译叙述文字与标题。
7. 翻译后不要新增/删除任何内容，**只替换英文叙述为中文**。
