### `clean room` 的含义

`clean room` 在这里不是物理意义上的“无尘室”，而是指一种**隔离资料来源的逆向工程方法**。研究人员只使用公开资料、公开代码、硬件观测结果和可复核的测量，不接触或引用厂商泄露的机密材料；必要时还会把资料分析和代码实现分隔开，以证明最终实现不是从受限材料中复制出来的。

因此，建议按上下文使用以下译法：

- `clean room`：首次出现可译为“净室逆向工程”，后文可简称“净室工作”；
- `clean-room work`：译为“净室逆向工作”或“净室工作”；
- `clean-room rules`：译为“净室规则”，首次出现时最好补充“只使用公开资料、不接触厂商泄露材料的研究规则”；
- `clean-room provenance`：可译为“净室来源溯源”。

不要把 `clean room` 直接理解成实验室场所，也不要在没有解释的情况下只写“净室”，否则读者很难理解它指的是资料来源和研究流程的约束。

### `floorsweeping` 的含义

`floorsweeping` 是芯片制造语境中的术语，不是普通意义上的“清扫地板”。它指在制造或产品分级阶段，通过 OTP 熔丝永久关闭有缺陷、多余或不符合目标规格的硬件单元。被处理的对象可能包括 GPC、TPC、SM、FBP、FBPA、NVLink 等。

它与驱动中的软件禁用不同：熔丝裁剪通常在制造阶段完成，状态由硬件永久记录，不是运行时开关，也不能通过普通软件重新启用。因此建议使用以下译法：

- `floorsweeping`：熔丝裁剪；
- `floorswept`：已被熔丝裁剪禁用；
- `floorsweep mask`：熔丝裁剪掩码；
- `floorswept unit`：被熔丝裁剪的硬件单元。

例如：

```text
Floorsweep masks are per die, not per SKU.
```

建议译为：

```text
熔丝裁剪掩码按晶片变化，而不是按 SKU 变化。
```

```text
The partition is floorswept.
```

建议译为：

```text
该分区已被熔丝裁剪禁用。
```
