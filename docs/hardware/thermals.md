# 热设计

## 本页内容

本页介绍 CMP 170HX 的散热器、晶片能够承受的温度、驱动暴露的传感器，以及资料库中记录的每一个实测温度。这里是热设计参考页；如果要选择实际使用的风扇或水冷头，请参见[散热](../operations/cooling.md)。同一问题的供电部分，请参见[供电与 PSU](../operations/power-and-psu.md)和[板载供电](power-delivery.md)。

有两个事实决定了其余所有问题。第一，**这块卡的散热器完全被动**：它是一块裸散热片，没有风扇，也没有驱动能够识别的风扇接口，设计用途是 1U/2U 服务器机箱中的强制风冷。所有公开捕获记录里的 `nvidia-smi` 都报告 `Fan Speed : N/A`，所以这块卡不会自行启动任何风扇；如果放进安静的桌面机箱，它会毫不客气地把自己烤热。第二，**这块卡很难真正加载起来**：在一块额定 250 W 的部件上，常规 FP32 烧机测试只能拉到约 60 W，因此，用这种测试验证过的散热器实际上并没有经过有效验证。

这里与解锁无关。对当前发布版解锁器以及全部 12 个未发布分支搜索 `thermal`、`pstate`、`power_limit`、`vid_pwm`、`clkdomain`、`freqDelta`、`0x20340`、`MHz` 和 `watt`，在任何补丁、脚本或配置中都找不到这些关键词。下文列出的所有热特性，都是出厂板卡和出厂 VBIOS 的属性。

## 物理散热器

| 属性 | 值 | 依据 |
|---|---|---|
| 散热器类型 | 完全被动的裸散热片，无风扇，无导流罩风扇 | 直接观察 |
| 槽宽 | 双槽，约 40 mm / 1.57 in 厚 | 安装支架的拥有者实测，中等置信度 |
| PCB 长度 | 裸板 27 cm；含 I/O 挡板和已插入的 EPS 连接器时为 29 cm | 直接测量 |
| PCIe 边缘连接器上方的净空 | 约 5-6 mm（1/4 in） | 实测，中等置信度 |
| 晶片周围的散热器螺栓孔位 | 中心距 57 x 68 mm（垂直方向 68 mm，水平方向 57 mm） | 直接测量 |
| 晶片封装 | 约 55 x 55 mm；晶片本身为 826 mm² | 测量加晶片数据库 |
| 紧固件 | Torx T10 和 T15 | 拆解 |
| 热界面，主要区域 | 1.5 mm 软垫 | 一位拆开卡并拍照的拥有者提供；另一位在没有把握的情况下猜测为 2 mm |
| 热界面，电感 | 3 mm 软垫 | 同一来源 |
| 热界面，晶片 | 液态导热材料 / 液态导热垫 | 同一来源 |
| 已发布的 CFM、静压、dBA、鳍片间距 | **均不存在** | 所有来源中都没有厂商或拆解数据 |

40 mm 的槽宽对选择支架很重要：面向 A100、H100、A20、A30、A40 和 CMP 170HX 宣传的 A100/H100 式 40 mm 涡轮支架，测量宽度为 1.57 in，因此可以安装在标准双槽间距中。

> [!NOTE]
> **未解问题：没人测量过这块散热片**
>
> 资料库中没有任何地方发布出厂 170HX 散热片的 CFM、静压、dBA 或鳍片间距数据。本 Wiki 中的所有气流数值，都是社区对“风扇加显卡”系统的测量，而不是散热片规格。最接近基准的数据，是两把 120 mm 风扇为四张卡散热、功耗限制为 `-pl 160` 时的结果。要解决这个问题，需要有人使用已知风扇曲线，在固定功耗限制下，将风扇工作点与晶片的稳态温度关联起来。

## 热限制

前四项数据直接来自一张已解锁的 10 GB 卡上的驱动（驱动版本为 `610.43.02`，捕获时间为 2026-07-25 18:32，P0，利用率 18%）。最后两行是社区观察结果，不是驱动报告的数据。

| 限制 | 值 | 层 |
|---|---|---|
| GPU 关机温度 | **98 C** | 硬件，驱动报告 |
| GPU 降速温度 | **95 C** | 硬件降速，驱动报告 |
| GPU 最大工作温度 | **85 C** | 驱动报告的工作上限 |
| 显存最大工作温度 | **95 C** | 驱动报告，HBM |
| 报告中的节流起点 | **~80 C** | 单次无来源读数，未提供遥测，低置信度 |
| GA100 显存节流（回忆） | ~85 C，"not on all bios" | 两次带保留语气的回忆，低置信度 |

在那次捕获中，这块卡报告 GPU 34 C、显存 48 C、`Fan Speed : N/A`；所有时钟事件原因都是 `Not Active`，包括 HW Thermal Slowdown 和 HW Power Brake Slowdown，而且每个事件计数器都为 `0 us`。

> [!NOTE]
> **未解问题：节流分层是推断出来的，尚未确立**
>
> 关于“什么时候开始节流”，目前有四个记录在案的数字：80 C（一位测试者自己的遥测）、85 C（两次关于 GA100 的回忆，以及驱动报告的 Max Operating Temp）、95 C（驱动报告的 Slowdown Temp），以及“above 100 C”（用于描述一张散热完全失效的显卡）。这些数字可能分别对应不同层级，而且都可以成立：80 C 时发生较软的 VBIOS 级时钟降低，85 C 时达到驱动工作上限，95 C 时发生硬件降速，而完全没有冷却回路时则会失控升温。**没人发布过一份将时钟降低与温度对应起来的节流日志。**能够最终确认这一点的，是记录从 75 C 扫到 95 C 的 `nvidia-smi --query-gpu=temperature.gpu,clocks.sm,clocks_throttle_reasons.active --format=csv -l 1` 日志。

### 社区设计目标

独立于驱动限制，测试者逐渐将**负载下核心温度 70 C、显存热点 75-76 C**确定为散热方案的设计目标。90 C 的热点温度被视为不可接受，也是拒绝使用单颗 40 mm 风扇的依据。在最终形成这一共识的交流中，一位正在选购风扇的参与者询问芯片达到 90 C 是否可以接受，随后说自己看到节流会从 80 C 开始，得到的回答是“Absolutely not!”。80 C 这个数字旁边没有附带遥测数据，因此应把它视为一次读数，而不是一次测量。

## 传感器与遥测

这块卡只暴露 GPU 温度和显存温度，没有其它热传感器。它没有风扇转速计、没有按 HBM 堆栈分别提供的传感器、没有暴露的 VRM 或热点差值传感器；由于卡上没有风扇，也不存在 `nvidia-settings` 风扇控制路径。

```bash
# 静态限制和当前读数
nvidia-smi -q -d TEMPERATURE

# 连续日志，每秒一行，适合找出真实的节流点
nvidia-smi --query-gpu=timestamp,temperature.gpu,temperature.memory,clocks.sm,\
clocks.mem,power.draw,clocks_throttle_reasons.active --format=csv -l 1
```

已确认 170HX 存在的字段：

| 字段 | 真实捕获中确认的值 |
|---|---|
| `GPU Current Temp` | `34 C`（空转，已解锁 10 GB） |
| `GPU Shutdown Temp` | `98 C` |
| `GPU Slowdown Temp` | `95 C` |
| `GPU Max Operating Temp` | `85 C` |
| `Memory Current Temp` | `48 C`（空转） |
| `Memory Max Operating Temp` | `95 C` |
| `Fan Speed` | 所有公开捕获中均为 `N/A` |
| Clocks Event Reasons | 空转时全部为 `Not Active`；所有计数器均为 `0 us` |

`nvtop` 会在一行中报告同样的传感器信息，这也是大多数测试者粘贴出来的内容：

```text
GPU 1440MHz MEM 1890MHz TEMP 76C FAN N/A POW 278 / 300 W
PCIe GEN 1@ 4x
GPU 100%  MEM 57.534Gi/64.000Gi
```

一位测试者在制作风扇曲线时给出了一条实用经验：如果根据报告中的**热点**传感器驱动曲线，控制器会不断来回调节；**晶片温度更适合作为控制输入**。

## 泄漏反馈与热失控

GA100 存在真实的、由泄漏驱动的正反馈回路。结温越高，CMOS 泄漏电流越大；泄漏电流越大，产生的热量越多；热量越多，又会进一步增加泄漏。

对这一现象最干净的测量，是一次意外获得的结果。一位研究者在一张已经安装水冷头、但水冷头内没有冷却液的卡上进行了干运行：空转功耗从约 **40 W** 开始，在达到 **80 C** 时升到 **60 W**，而在断电时仍然继续上升。

> [!CAUTION]
> **安装了水冷头但没有冷却液的显卡，绝不要通电运行超过 5 分钟**
>
> 干燥的水冷头比完全没有水冷头更糟，因为它会形成隔热层。实测从 40 W 升到 60 W 的过程在 80 C 时还没有稳定下来。如果必须先干装水冷头来检查净空，请在 5 分钟内断电。

这会带来两个后果，一个良性，一个并不良性：

- **良性：**更好的散热会降低显卡的空转功耗，因为它既能抑制泄漏项，也能带走热量。这是不同测试者之间出现 30 W 与 44 W 空转功耗差异时，最可能的解释。
- **不良性：**如果散热彻底失效，GA100 不会稳定在节流点。一段来自 A100 级别设备实际操作经验的描述是：“The thermal throttling runs at such a high power that if the cooling fails, it'll thermally throttle, but to a temperature above 100 degrees, that then consumes more power, thus increased temperature... and you end up with a volcano.” 热节流运行在如此高的功率上，所以散热失效后，显卡虽然会进行热节流，却会升到超过 100 度；这又会消耗更多功率，使温度继续升高……最终就会变成一座“火山”。确切温度取决于 BIOS，而且在同一场交流中也存在争议，因此可以认为曲线形状已经得到确认，但具体数字尚未确立。

### 风冷下的 HBM 下限

一位测试者在一张安装了 140 mm 导流罩、使用 120 mm 风扇 @ 3000 RPM 的卡上，完成多种功耗和时钟配置扫描后总结道：“with the right tuning.. the temp baseline is right here.. you can save watts, but you wont be able to drop temps on air”（调校正确后，温度基线就在这里；可以节省功耗，但无法在风冷下继续降温），以及“getting lower hbm temps on air seems impossible”（在风冷下进一步降低 HBM 温度似乎是不可能的）。在这些设置（`EFF / Balanced +300MHz / 1400`）下，30 分钟的 `gpu_burn` 测试完成且没有报错。

> [!NOTE]
> **未解问题：HBM 的温度下限是散热限制，还是 HBM 本身的固有特性？**
>
> 有人直接请求水冷头的 HBM 温度数据，但没有得到回应，因此这个温度下限在向下方向上仍然没有边界：没人知道水冷能否让 HBM 的温度实质性地低于风冷。这个领域中成本最低、价值最高的单项实验，是让那位使用廉价水冷头、运行一小时得到核心 48 C / 显存 58 C 的拥有者，重新执行同一组 `EFF / Balanced +300MHz / 1400` 扫描，并记录显存传感器。

## 热通常不是瓶颈

这一点往往出人意料，也会改变你在散热上应该如何花钱。

- 在散热良好的卡上，把功耗上限从 250 W 提高到 300 W，只带来 **+2.8%** 的 BF16 吞吐提升（约从 180 提高到 185 TFLOPS），而且**核心和显存都低于 65 C**。核心本身就是不愿意继续提高时钟。
- 带 OC VBIOS 的 8 GB 卡运行 `mmapeak` 时停在 **1470 MHz、仅消耗约 150 W**，GPU-T 报告 `PerfCap: None`，即使功耗上限已经设为 300 W 也是如此。这个时钟上限既无法由功耗解释，也无法由任何已暴露的上限解释，目前仍然没有答案。
- 80 GB 配置的不稳定与温度和供电都无关：发生崩溃的卡在相关负载期间**从未消耗超过约 80 W**。

不过，确实存在一种真正的热故障模式。从未重新涂导热膏或更换导热垫的卡，可能会出现严重节流：一位拥有两张 8 GB 卡的用户只能给其中一张跑基准测试，因为另一张“throttles a lot”（节流很严重），需要重新更换导热垫并涂导热膏。如果一张卡在相同气流下比邻近的卡早得多地节流，应先怀疑出厂热界面，再怀疑晶片本身。

## 气流指南

目前没有经过测量验证的具体需求，只有一组从上述测量结果中总结出来的规则。这些规则已经在[散热](../operations/cooling.md)中整理，并与真实散热器进行了对比。

| 量 | 值 | 状态 |
|---|---|---|
| 满功率运行的目标静压 | 20 mm | 从规格推导出的建议，**未经测量** |
| Arctic P12 Pro CO 发布规格 | ~7 mm 静压，130 m³/h | 厂商规格；不过，这把风扇在 `-pl 160` 下确实让 4 张卡保持在 65 C 以下 |
| 最低实用风扇功率 | 高于 4 W，即 12 V 下 0.35 A | 实用指导，没有受到质疑，但未实测 |
| 首选风扇类别 | 径流式高静压涡轮，或 38 mm 厚轴流风扇 | 对于 300 W 和双卡场景，薄型 120 mm 风扇受到质疑 |
| 气流方向 | **拉，不要推** | 多份一手报告一致指出，推式套筒导流罩会产生回流 |
| 单颗 40 mm 风扇 | 无论转速多高都不够 | 1 x S4028-15K 会得到 90 C 热点；2 x 则为 70 C / 76 C |

无论使用哪种散热器，**都必须同时给 VRM 散热**，不能只冷却晶片。拆掉导流罩并在晶片上安装压力固定式塔式散热器后，仍然需要额外使用一把 80-120 mm 风扇吹向供电区域。关于这些部件的位置，请参见[板载供电](power-delivery.md)。
